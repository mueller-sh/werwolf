# Werwolf 3.0

Interaktive Web-App zur Spielleitung.

## GitHub Pages aktivieren

Im Repository **Settings → Pages** öffnen und bei **Build and deployment**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Danach ist die App unter:

https://mueller-sh.github.io/werwolf/

erreichbar.

Die App speichert Spielstände lokal im Browser und bietet Export/Import als JSON.
